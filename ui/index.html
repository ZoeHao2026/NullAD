HTTPS 浏览器扩展

完整 HTTPS 资源 URL 与页面元素过滤由浏览器扩展执行，无需安装根证书。扩展需单独安装并设置。

  1. 解压 NullAD 扩展 ZIP，保留包含 manifest.json 的目录。
  2. 在 Chrome / Edge 扩展页开启开发者模式，选择“加载已解压的扩展程序”，选中该目录。 chrome://extensions / edge://extensions
  3. 打开扩展设置，选择启发式模式和允许域名；扩展设置独立于桌面。

扩展与已有 HTTP / SOCKS / TUN / VPN 代理路径独立；NullAD 网络代理使用显式上游链，不自动接管这些代理。
